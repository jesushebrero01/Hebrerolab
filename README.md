# HebreroLab

Web estática de presentación para HebreroLab, construida con HTML, CSS y JavaScript.

## Estructura
- `index.html`: inicio
- `work.html`: portfolio con filtros
- `studio.html`: presentación y metodología
- `contact.html`: formulario que prepara un correo
- `assets/styles.css`: estilos responsive
- `assets/app.js`: menú, animaciones, filtros y formulario

## Publicación en Cloudflare Pages
- Framework preset: None
- Build command: dejar vacío
- Build output directory: `/` (o `.` si el panel lo solicita)

## Antes de publicar
1. Sustituir las imágenes de referencia por recursos propios o con licencia.
2. Cambiar `hola@hebrerolab.com` por un correo real.
3. Revisar textos, metadatos y enlaces.
4. El formulario abre el cliente de correo; no almacena ni envía datos a un servidor.
5. Las fuentes, GSAP y fotografías de demostración se cargan desde servicios externos.

Este proyecto es una interpretación original inspirada en referencias visuales de estudios creativos. No contiene código, textos ni recursos propietarios de terceros.
